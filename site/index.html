The protocol is open

Every token below is a 546-sat UTXO in the exact on-chain format Twetch uses for Twonks — minted without touching Twetch, from an ordinary BSV wallet:

OP_HASH160 <H1> OP_EQUALVERIFY
OP_DUP OP_HASH160 <H2> OP_EQUALVERIFY OP_CHECKSIG
OP_RETURN <{"attributes":[…],"image":"b://…","number":N,"title":"…"}>
  • H1 = HASH160(raw 32-byte collection id) — a public tag, not a permission.
  • H2 = owner's pubkey hash. Unlock order: <sig> <pubkey> <collection-id>.
  • BSV's OP_RETURN semantics keep these spendable: after CHECKSIG the top item is true.
  • Proven here: TWONKLAB #1 moved wallets (transfer tx), and an accidental double-mint was burned back to plain sats (burn tx).

Minter: bsv twonk-mint in bsvOS walletd (src/twonk.ts) · wallet never exposes keys; transfers sign offline with a held WIF (tools/transfer.mjs).

How buying works

One atomic swap transaction: buyer funds + seller's token in → payment to seller + token re-issued to buyer's key + marketplace fee + buyer change. No escrow, no custodial hop. Trade execution UI is next; the construction is documented and already proven by the #1 transfer.
